# Stepwise · 一步步带你学会

一个**完全在本机运行**的学习应用。照着 Sia（AskSia）那套教学法做的：**先给提示 → 一步步演练 → 反过来考你 → 几天后再回来复习**，而不是一上来把答案甩给你。

## 30 秒跑起来

```bash
cd projects/stepwise-learn
python -X utf8 start.py
```

Windows 也可以直接双击 `start.bat`。启动后浏览器会自动打开 `http://127.0.0.1:8765/`。

- **零依赖**：只用 Python 标准库，不用 pip install、不用 Node、不用联网、不用注册账号。
- **零外传**：所有进度只写在本机 `data/learn.db`，没有遥测、不上传任何内容。
- 端口被占用会自动换一个，实际地址看启动时的输出。
- 停止：按 `Ctrl+C`。

## 怎么用它学一个知识点

1. 左边选一门课里的知识点（比如「链式法则」）。
2. **① 提示**：它先抛一个问题，不给答案。你可以点「再给一点提示」换角度。
3. **② 演练**：点「看第一步」，白板**一次只出现一条**。每一步都会点出「常见的卡点」。
4. **③ 检查站**：步骤看完，换它反过来问你一题。答错会**自动退回你卡住的那一步**并记下错步。
5. **④ 测验**：两道小测，答对才算掌握。
6. 完成后自动排进复习队列；答对按 **1 → 3 → 7 → 16 天** 拉长间隔，答错退回 1 天。首页「今日复习」只列到期的项，点「想起来了 / 忘了」即可。

右上角「清空进度」会重置本机数据（会先弹确认）。

## 三门内置课（9 个知识点）

| 课程 | 知识点 |
|---|---|
| 学术英语写作 | 论点句 / 段落衔接 / 引用整合 |
| 微积分基础 | 链式法则 / 极限与 0/0 / 分部积分 |
| 学习方法（元技能）| 主动回忆 / 间隔复习 / 费曼式讲解 |

内容都按「立场 + 范围 + 理由」「LIATE」「given-new」这类可复述的结构写，术语保留英文，讲解用中文，适合留学生场景。要加课只要照 `curriculum.py` 里的结构往 `COURSES` 里加一项即可，服务端和前端都不用改。

## 接 AI（可选，不接也完整可用）

默认 **离线模式**：用课程数据 + 苏格拉底式模板生成讲解，断网照样跑完整个流程。

想让讲解更灵活，可以接任意 OpenAI 兼容接口：

```bash
# Windows PowerShell
$env:LEARN_API_BASE = "https://api.example.com"   # 不含 /v1，代码会补
$env:LEARN_API_KEY  = "[API_KEY]"
$env:LEARN_MODEL    = "gpt-4o-mini"
python -X utf8 start.py
```

```bash
# macOS / Linux
export LEARN_API_BASE="https://api.example.com"
export LEARN_API_KEY="[API_KEY]"
export LEARN_MODEL="gpt-4o-mini"
python3 -X utf8 start.py
```

- 只从环境变量读 key，**不写进代码、不写进数据库、不写进日志**。
- 接口超时/报错会**自动回退离线**，学习流程不会中断。
- 有条硬护栏：即使 AI 想提前剧透，提示阶段出现过任何未揭示的步骤内容，就丢弃该回复改用离线讲解。

## 自检

```bash
python -X utf8 selftest.py
```

28 项断言，覆盖：离线可用、提示不泄答案、白板逐步揭示、答错回退并标记错步、复习调度（答对推进/答错重置）、幂等、凭据不外泄、全部 HTTP API。全通过会打印 `结果: 28 通过 / 0 失败` 且退出码为 0。

## 文件结构

| 文件 | 作用 |
|---|---|
| `start.py` / `start.bat` | 一键启动 |
| `server.py` | 本地 HTTP 服务与 JSON API（只监听 127.0.0.1） |
| `static/index.html` | 单页界面：课程树 / 分步白板 / 检查站 / 掌握度 / 复习队列 |
| `curriculum.py` | 课程包数据 |
| `pedagogy.py` | 四阶段状态机与帧生成 |
| `brain.py` | 离线规则引擎 + 可选 AI 接口（自动回退） |
| `store.py` | SQLite：会话、事件、掌握度、复习队列 |
| `selftest.py` | 端到端自检 |
| `PLAN.md` | 实施计划 |

## 和 Sia 的对照

| Sia 的做法 | 本应用 |
|---|---|
| 服务器下发带时间轴的帧，白板逐步揭示 | 本地状态机逐帧下发，白板一次一条 |
| 提示 → 演练 → 检查站 → 测验四阶段 | 同样的四阶段，答错退回对应错步 |
| progress/sync 游标 + 掌握度追踪 | SQLite 记掌握度与错步 |
| credits 按分钟预扣、订阅分档 | 无账号、无计费（本地工具） |
| Tauri + WebView2 桌面壳 | 浏览器即客户端，零安装 |
| AI 推理全在服务端 | 默认离线规则引擎，可选接 AI |

**没照搬的部分**：实时语音课（需要 ASR/TTS、WebSocket 与音频时钟对齐）、桌面宠物、白板笔迹动画、多端同步、LMS 集成——这些要么需要外部服务，要么对「本地学习工具」是过度设计。教学法内核保留了。

## 已知边界

- 会话状态在服务端内存里，重启服务后**当前这一节**会回到起点；但掌握度、错步、复习排期都在 SQLite 里，不会丢。
- 课程内容是内置的 9 个知识点，不是无限题库；接了 AI 之后讲解会更灵活，但题目仍来自课程包。
- 浏览器需支持 ES6（近几年的 Chrome/Edge/Firefox/Safari 都可以）。
